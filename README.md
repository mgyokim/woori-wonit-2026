## 💡 알게 된 것

**에러 없이 틀리는 코드가 제일 무섭다** — 네 번 반복해서 만난 패턴이다.
AI 디버깅 버그 5개 중 4개가 콘솔 무반응이었고, `default` 없는 `switch` 는 조용히 아무것도 안 하고,
`0 < age` 는 부등호만 뒤집힌 채 문법 검사를 통과하고, `NaN` 이 섞인 `sort` 는 정렬을 포기한다.
**콘솔이 안 알려주는 건 값을 직접 넣어봐야 보인다.**
→ [Day 2](./daily-log/0827.md) · [Day 4](./daily-log/0831.md) · [Day 5](./daily-log/0901.md)

**입력창에서 받은 값은 언제나 문자열이다.**
`"10000" + 500` 은 `10500` 이 아니라 `"10000500"` 이다. 숫자처럼 생겼다고 숫자가 아니라서,
금액을 계산하기 전에 반드시 `Number()` 로 바꾼다. `==` 대신 `===` 를 쓰는 이유도 같다.
→ [Day 4](./daily-log/0831.md)

**`>` 와 `>=` 는 한 글자 차이지만 은행에서는 사고다.**
잔액 500,000원에 이체 500,000원이면 `amount > balance` 는 거짓 — 전액 이체가 통과한다.
"넘으면 막는다"인지 "다 쓰면 막는다"인지에 따라 부호가 달라지고, **경계값을 넣어보지 않으면 안 보인다.**
→ [Day 4](./daily-log/0831.md)

**AI의 첫 답을 최종본으로 받지 않는다.**
소수점 버그에 AI는 `toFixed(2)` 를 권했지만 문자열이 되는 **오답**이었다.
`<div>` 로 채워진 답에 "여기서 시맨틱 태그를 쓸 수 있는 곳이 있어?" 라고 되묻자 결과가 바뀌었다.
`[재현 조건] / [기대 동작] / [실제 동작]` 으로 묻고, **"먼저 설명, 그다음 코드"** 를 강제하면 검증할 수 있다.
→ [Day 2](./daily-log/0827.md) · [Day 3](./daily-log/0828.md)

- **Daily Log** : `daily-log/MMDD.md`, 첫 두 줄은 `# Day N — YYYY.MM.DD (요일)` + `> 학습 키워드`
- **Daily Log 구성** : `오늘의 핵심`(3가지 이내) → 직접 확인한 것 · 실습 → `회고`.
  **강의자료를 옮겨 적지 않는다** — 검색하면 나오는 내용 대신 *내가 걸린 것 · 판단한 것 · 틀렸던 것*을 남기고,
  원자료는 상단에 링크로만 건다. 나중의 나와 처음 보는 사람이 **핵심을 먼저** 읽을 수 있어야 한다.
- **README 승격** : Daily Log에 쌓인 것 중 **반복해서 나타난 패턴**만 루트 README의 `알게 된 것` 으로 올린다.
  하루짜리 사실이 아니라 여러 날에 걸쳐 확인된 것만.
- **Daily Log 표** : 날짜 오름차순 — 새로운 날짜는 표 맨 아래에 추가, 달이 바뀌면 `### YYYY.MM` 소제목 추가
- **회고** : Daily Log 마지막은 `## 회고` — Keep(유지할 것) · Problem(개선할 것) · Try(시도할 것) 각 1~2줄
- **단원 폴더** : 각 폴더의 `README.md`가 해당 단원의 목차 역할. **문법과 기본 개념은 여기까지만** 둔다
- **실습 기록** : 내세울 만한 실습은 단원 폴더에 STAR(Situation · Task · Action · Result)로 정리
- **커밋 컨벤션** : `feat` 기능 추가 / `fix` 버그 수정 / `doc` 문서 작성 · 수정 / `chore` 기타 설정
