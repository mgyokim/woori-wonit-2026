## 오늘 학습한 내용

### Git

- 분산 버전 관리 시스템(DVCS). 로컬에 전체 히스토리를 두고 작업 후 원격에 반영한다.
- 작업 영역 흐름 : Working Directory → (`add`) → Staging Area → (`commit`) → Local Repository → (`push`) → Remote Repository

**기본 설정**

```bash
git config --global user.name "이름"
git config --global user.email "이메일"
```

**저장소 생성 & 원격 연결**

```bash
git init                  # 로컬 저장소 초기화
git remote add origin <저장소 주소>
git branch -M main        # 기본 브랜치 이름을 main으로
git push -u origin main   # 최초 push (업스트림 설정)
```

**작업 반영 흐름**

```bash
git status         # 변경 사항 확인
git add <파일>     # 스테이징 (git add . : 전체)
git commit -m "메시지"
git push           # 원격 저장소에 반영
git pull           # 원격 변경 사항 가져오기
git log            # 커밋 히스토리 확인
```

**커밋 메시지 컨벤션**

- `feat` : 새로운 기능 추가
- `fix` : 버그 수정
- `doc(s)` : 문서 작성 · 수정
- `chore` : 설정 파일 등 기타 변경

### Markdown

- 일반 텍스트로 문서 서식을 작성하는 경량 마크업 언어. README, 학습 노트 작성에 사용한다.

| 문법 | 사용법 |
| --- | --- |
| 제목 | `# H1` `## H2` `### H3` (`#` 6개까지) |
| 강조 | `**굵게**` `*기울임*` `~~취소선~~` |
| 목록 | `- 순서 없는 목록` / `1. 순서 있는 목록` (들여쓰기로 하위 항목) |
| 링크 | `[표시할 텍스트](주소)` |
| 이미지 | `![대체 텍스트](이미지 주소)` |
| 인용 | `> 인용문` |
| 인라인 코드 | `` `코드` `` |
| 코드 블록 | ```` ```언어 ... ``` ```` |
| 구분선 | `---` |
| 표 | `\| 헤더 \| 헤더 \|` 아래 `\| --- \| --- \|` |
| 체크박스 | `- [ ] 할 일` / `- [x] 완료` |

- 줄바꿈은 문장 끝에 공백 2칸을 넣거나 빈 줄로 문단을 나눈다.
